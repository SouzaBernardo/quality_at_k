# output/

This directory contains two types of content: **ClassEval benchmark inputs**
(provided separately and not generated by this study) and **outputs produced by
the project pipeline**.

---

## Benchmark Inputs

### `ClassEval_output/`
Raw files provided by the [ClassEval](https://github.com/FudanSELab/ClassEval)
benchmark. This project does not generate them; they must be present before
running the pipeline.

| Path | Description |
|---------|-----------|
| `ClassEval_output/model_output_v1.0.0/` | JSONs with each LLM's raw responses to the 100 tasks |
| `ClassEval_output/result/detailed_result.json` | ClassEval functional results: status (`Success`, `PartialSuccess`, `Fail`, `Error`) and `pass@1` for each task |

---

## Study Outputs

### `solutions/`
Generated by `scripts/take_solution.py`.

| Path | Description |
|---------|-----------|
| `solutions/{model}/*.py` | Sanitized Python code (without Markdown fences or surrounding prose), used as SonarQube input |
| `solutions/originals/{model}/*.py` | Raw model response, before cleanup |

### `results/`
Generated by the pipeline (`pipeline.py`).

| File | Generated by | Description |
|---------|------------|-----------|
| `results/pass_results.csv` | `take_solution.py` | Mapping `(model, task)` → `pass_val` + functional status |
| `results/raw/sonar_metrics.csv` | `extract_sonar_metrics.py` | Aggregate SonarQube metrics by project |
| `results/raw/sonar_metrics_{project}_files.csv` | `extract_all_sonar_metrics_per_file.py` | Per-file SonarQube metrics, one CSV per project |
| `results/combined_sonar_metrics.csv` | `merge_sonar_metrics.py` | Main dataset: SonarQube metrics + Quality@1 (FQS) per task |
| `results/aggregated_results.csv` | `aggregate_results.py` | Mean FQS grouped by `(model, strategy, status)` |

### `validation/`
Generated by `scripts/generate_comparations.py`.

| File | Description |
|---------|-----------|
| `validation/comparation-{model}.html` | Side-by-side HTML diff between each model's raw response and sanitized code |
